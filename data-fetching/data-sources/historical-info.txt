FiveThirtyEight Historical Senate Polls CSV
===========================================

Source: FiveThirtyEight (ABC News) — GitHub data repository
Status: Public, no authentication required, still accessible as of Sept 2026

Direct download URL:
https://projects.fivethirtyeight.com/polls-page/data/senate_polls_historical.csv

GitHub repository (README with all available files):
https://github.com/fivethirtyeight/data/tree/master/polls

README raw (full file index):
https://raw.githubusercontent.com/fivethirtyeight/data/master/polls/README.md

---

Dataset coverage:
- Cycles: 2010 through early 2025 (FiveThirtyEight shut down March 2025)
- Recommended filter for this project: cycle == 2022 (same 35-seat Class II map structure as 2026)
- Approx. rows for cycle 2022: ~15,000 (one row per candidate per poll)

Key columns:
  poll_id        — unique poll identifier
  state          — state name
  cycle          — election year (2010, 2012, ..., 2024)
  start_date     — poll field start date
  end_date       — poll field end date
  pollster        — polling firm name
  fte_grade       — FiveThirtyEight pollster quality grade (A+, A, B, C...)
  sample_size     — number of respondents
  population      — lv (likely voters) / rv (registered voters) / a (adults)
  party           — DEM / REP / IND
  candidate_name  — candidate full name
  pct             — vote share percentage

Justification for using 2022 instead of 2026:
  The MSN/JunkCharts tile map (July 2026) uses the same Class II Senate structure
  as the 2022 midterm map. The dataset schema, state coverage, and visualization
  flaws (color overload, missing flip detection, no competitiveness gradient) are
  identical across cycles. The 2022 historical CSV is freely accessible and
  provides sufficient volume for all three required preprocessing steps.
