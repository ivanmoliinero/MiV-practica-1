# Problemas con el plot
En este texto presentamos los problemas que el plot plantea.

## Problemas que entorpecen la comunicación
El principal es no hacer la comparativa con el pasado, no se puede ver la conclusión de que los demócratas creen ser más optimistas.

## Problemas del plot en si
- Mapa desastre, parece tabla periodica.
- Falta de leyenda (confusion de colores, tonalidad, significados, etc.).
- Confusion de Alaska y Hawaii como leyendas.
- Escala de colores no adecuada? Puede no representar realmente qué colores son representativos realmente?
