# Framework selection
En este documento se analizan los frameworks propuestos para el lenguaje Python para el tipo de visualización que queremos conseguir. Buscamos un framework que ofrezca interactividad del plot.

## ¿Cómo conseguimos interactividad?
Para conseguir interactividad, no podemos depender de un PDF o PNG estáticos, necesitamos algo más potente.
Podemos usar una app en formato web o escritorio. El uso del formato web justificaría la portabilidad (si lo desplegamos en algún servicio en la nube). Si se debe generar en local, el tratamiento de dependencias es igual tanto para app como para web.

## Frameworks
A continuación, se analizan cada uno de los frameworks propuestos en el enunciado de la práctica sobre este lenguaje.

### Streamlit
Fácil interacción en formato web. No dependencias externas.

### Shiny
Igual que Streamlit, pero la documentación muestra mejores ejemplos de visualizaciones.
